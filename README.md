# Mini-Courier Planner

Python capstone implementing Merge Sort, 0/1 Knapsack DP, Dijkstra shortest paths and a Nearest Neighbor TSP approximation.

## Folder structure
```text
Mini_Courier_Planner/
├── __pycache__/ (created automatically by Python)
├── charts/ (runtime charts)
├── data/{small,medium,large}/ (parcels.csv and graph.csv)
├── screenshots/ (add your own VS Code/output screenshots)
├── tests/test_algorithms.py
├── README.md, REPORT.docx, REPORT.md
├── algorithms.py, planner.py, benchmark.py, data_gen.py
└── benchmark_results.json (generated by benchmark.py)
```

## Setup and run (VS Code terminal)
1. `python -m pip install matplotlib`
2. `python data_gen.py` (regenerates the three datasets)
3. `python planner.py --dataset small`
4. Repeat with `medium` and `large`.
5. `python benchmark.py` (creates JSON results and five charts).
6. `python -m unittest discover -s tests -v`
Use `py` instead of `python` on Windows if needed.

## Data
Each parcel has ID, name, priority (1-5), deadline, weight (kg), and value. Each graph CSV row has source, destination and non-negative distance in km. Roads are undirected. Dataset sizes: 6, 25 and 60 parcels.

## Complexity
- Merge Sort: O(n log n) time, O(n) extra space.
- 0/1 Knapsack: O(nW) time and O(nW) table space.
- Dijkstra with heap: O((V+E) log V).
- Nearest Neighbor TSP: O(V^2), approximate and not guaranteed optimal.

## Important
Dijkstra calculates shortest paths from one source. TSP tries to visit every location and return to the depot. They solve different problems. The generated sample graphs are complete and undirected. Runtime values vary by computer. Put screenshots captured on your laptop in `screenshots/`.
